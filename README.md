# 刘洋睿 个人作品集（基础版）

基于 React + Vite 的暗色系个人作品集基础版本，面向 PC 展示。请按下列步骤运行并替换占位素材。

运行
1. npm install
2. npm run dev
3. 打开浏览器访问显示的本地地址（通常 http://localhost:5173）

替换素材（public 目录）
- /public/video.mp4  —— 首页视频背景（可用短循环视频）
- /public/avatar.jpg  —— 头像
- /public/project1.jpg /project2.jpg /project3.jpg /project4.jpg —— 作品截图

联系方式已设置：3545935829@qq.com

后续优化建议
- 给每个作品卡片添加作品详情页或 modal 弹窗（包含说明、流程图、多张图片）
- 使用自定义字体（更显高级感）并调整排字
- 增加微交互（鼠标悬停、卡片入场动效）
- 替换色彩为你的品牌色，并微调亮度/对比，达到“高级克制”的视觉效果
- 提供中文/英文切换（如果需要）
